# Eglеs — Jāņaiši, 17–27 марта 1945

**https://kabanec.github.io/kurzeme-1945/**

Реконструкция боёв 17–27 марта 1945 года юго-западнее Салдуса (Курземе, Латвия) —
1-й батальон 96-го гвардейского стрелкового полка 30-й гвардейской стрелковой дивизии,
15-й гвардейский стрелковый корпус, 10-я гвардейская армия, 2-й Прибалтийский фронт.

A reconstruction of the fighting of 17–27 March 1945 south-west of Saldus, Courland,
built from the war diaries, combat reports and orders of the units involved, read against
the Latvian 1:75,000 sheet the staff themselves used.

- `index.html` — русская версия (по умолчанию)
- `en.html` — English version

Both files are self-contained: no build step, no external assets beyond the web fonts.
Each carries a Рус / Eng switch in the top right.

Sources are cited in place. Where two documents disagree, both readings are printed and
neither is averaged; corrections made after publication are stated in the text rather than
applied silently.
